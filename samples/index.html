C · Profile Templates — the company picks ONE, everyone gets it

The early-Facebook rule: same boxes, same order, same size for all 150 people. A member can fill in their bio, add their own photos and personal notes — inside the same boxes everyone else has. No points, no badges, no levels, no leaderboard on any profile. Profiles are information, not a scoreboard.

How picking works: A-blocks can be used anywhere, any time. B-templates load as empty skeletons, same as the 10 homepage templates. C is picked ONCE per company by an admin — after that the choice disappears and every profile is built from it; members only edit their own words and photos inside it. Points: none anywhere in the product — no points system at all (owner decision, 2026-11-06). Shout-outs and thank-you posts are just posts; nothing is scored.
