Avatar UI Components — Live Samples

Your 10, built as the working widgets they are — sprinkled-size pieces that live in feeds, comments, directories, document headers and sidebars, on top of the normal profile pages. Initials stand in for photos in these samples; the real build uses each person's uploaded headshot. One flag: #6's "trivia badge" flavour touches the points-and-badges ban you set tonight, so I built it as factual milestone markers (years of service, a real award) — nothing earnable, nothing scored. Your call if even that goes.

Working samples for the JV intranet avatar system — these 10 are components, not pages: they attach to the standard profile (company template C1–C10) and appear wherever avatars appear. Status ring state, department frames and milestone markers are driven by real data in production (presence, department, start date, awards). Kudos note: the radial menu's "Say thanks" sends a plain thank-you post — no points, per the owner's product-wide ruling.
