# Axis — public demo mirror

Public demo mirror for **Axis**, a secure company intranet platform (private source: `zerononeex/axis`, never built here).

The Axis application itself is a server app (database + sign-in), so it can't run on GitHub Pages. This mirror hosts the verified design & demo artefacts: the JV Developments homepage mock (`jv-home/`), all interactive samples pages (`samples/`), and the homepage research gallery (`gallery/`). Everything runs on fictional demo data.
