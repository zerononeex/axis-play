AXIS

A secure company intranet — a website behind a login wall — with a no-code website builder anyone can use, a deep template library, people profiles, and an "Ask HR" chatbot that answers from live policy documents instead of stale file copies.

Status: full demo build complete and independently verified — all 7 build batches, 197/197 automated tests including an adversarial security suite (160 concurrent logins with tenant isolation, a 3,000-attempt hostile login flood, injection/XSS/CSRF/IDOR attacks — all blocked). Everything below runs on fictional demo data (JV Developments, 150 fictional staff). The application itself runs on a server (it needs a database and sign-in), so this public mirror hosts the design & demo artefacts; the app demo runs from the private repo.
